## Как тестировать в Swagger UI:

1. **Откройте**: http://localhost:8000/docs

2. **Тестирование Categories:**
   - `POST /categories/` - создание категории ✅
   - `GET /categories/` - список категорий ✅
   - `GET /categories/{category_id}` - получение по ID ✅
   - `PUT /categories/{category_id}` - обновление ✅
   - `DELETE /categories/{category_id}` - удаление ✅

3. **Тестирование Books:**
   - `POST /books/` - создание книги ✅
   - `GET /books/` - список книг с фильтрацией ✅
   - `GET /books/{book_id}` - получение по ID ✅
   - `PUT /books/{book_id}` - обновление ✅
   - `DELETE /books/{book_id}` - удаление ✅

## Примеры тестирования:

### Создание категории:
```json
{
  "name": "Новая категория",
  "description": "Описание"
}
```

### Создание книги:
```json
{
  "title": "Новая книга",
  "author": "Автор",
  "description": "Описание книги",
  "category_id": 1
}
```

### Фильтрация книг:
- По автору: `GET /books/?author=Толстой`
- По названию: `GET /books/?title=Война`
- По категории: `GET /books/?category_id=1`

## Важно:

- В Swagger UI можно использовать пути **с trailing slash** (`/categories/`) или **без** (`/categories`) - оба варианта работают
- При использовании curl или прямых запросов, FastAPI может делать редирект на версию с trailing slash - это нормально
