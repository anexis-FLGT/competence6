# Пошаговая инструкция по тестированию CRUD через Swagger UI

## Шаг 1: Запуск сервера

Откройте терминал и выполните:

```bash
cd /mnt/c/Users/Максим/Desktop/competence6
source venv/bin/activate
uvicorn main:app --reload
```

Вы должны увидеть сообщение:
```
INFO:     Uvicorn running on http://127.0.0.1:8000 (Press CTRL+C to quit)
INFO:     Application startup complete.
```

**Не закрывайте этот терминал!** Сервер должен работать.

## Шаг 2: Открытие Swagger UI

1. Откройте браузер (Chrome, Firefox, Edge и т.д.)
2. Перейдите по адресу: **http://localhost:8000/docs**
3. Вы увидите интерактивную документацию API с разделом "Books API"

## Шаг 3: Тестирование CRUD для Категорий (Categories)

### 3.1. CREATE - Создание категории

1. Найдите раздел **`POST /categories`** (зеленая кнопка POST)
2. Нажмите на неё, чтобы раскрыть
3. Нажмите кнопку **"Try it out"** (справа вверху)
4. В поле **Request body** введите JSON:
   ```json
   {
     "name": "Художественная литература",
     "description": "Романы, рассказы, повести"
   }
   ```
5. Нажмите кнопку **"Execute"** (синяя кнопка внизу)
6. Вы увидите:
   - **Response code**: `201` (Created)
   - **Response body**: JSON с созданной категорией (запомните `id`!)

**Создайте еще одну категорию:**
```json
{
  "name": "Научная литература",
  "description": "Научные книги и исследования"
}
```

### 3.2. READ - Получение списка категорий

1. Найдите **`GET /categories`**
2. Нажмите "Try it out"
3. Вы можете указать параметры:
   - `skip`: 0 (пропустить записей)
   - `limit`: 100 (максимум записей)
   - `name`: "image.png" (фильтр по имени, опционально)
4. Нажмите **"Execute"**
5. Вы увидите список всех категорий

### 3.3. READ - Получение категории по ID

1. Найдите **`GET /categories/{category_id}`**
2. Нажмите "Try it out"
3. В поле **`category_id`** введите `1` (или ID созданной категории)
4. Нажмите **"Execute"**
5. Вы увидите данные категории

### 3.4. UPDATE - Обновление категории

1. Найдите **`PUT /categories/{category_id}`**
2. Нажмите "Try it out"
3. В поле **`category_id`** введите `1`
4. В **Request body** введите:
   ```json
   {
     "name": "Художественная литература",
     "description": "Обновленное описание категории"
   }
   ```
5. Нажмите **"Execute"**
6. Вы увидите обновленную категорию

### 3.5. DELETE - Удаление категории

**⚠️ Внимание:** Удаляйте только категории, в которых нет книг!

1. Найдите **`DELETE /categories/{category_id}`**
2. Нажмите "Try it out"
3. Введите ID категории (например, `2`)
4. Нажмите **"Execute"**
5. Ответ будет `204 No Content` (успешное удаление)

## Шаг 4: Тестирование CRUD для Книг (Books)

### 4.1. CREATE - Создание книги

1. Найдите **`POST /books`**
2. Нажмите "Try it out"
3. В **Request body** введите (используйте `category_id` из созданных категорий):
   ```json
   {
     "title": "Война и мир",
     "author": "Лев Толстой",
     "description": "Роман-эпопея о войне 1812 года",
     "category_id": 1
   }
   ```
4. Нажмите **"Execute"**
5. Запомните `id` созданной книги

**Создайте еще несколько книг:**
```json
{
  "title": "Преступление и наказание",
  "author": "Федор Достоевский",
  "description": "Психологический роман",
  "category_id": 1
}
```

```json
{
  "title": "Краткая история времени",
  "author": "Стивен Хокинг",
  "description": "Популярная книга о космологии",
  "category_id": 2
}
```

### 4.2. READ - Получение списка книг

1. Найдите **`GET /books`**
2. Нажмите "Try it out"
3. Попробуйте разные фильтры:

   **Без фильтров:**
   - Оставьте все поля пустыми
   - Нажмите "Execute"
   - Увидите все книги

   **Фильтр по автору:**
   - В поле `author` введите: `Толстой`
   - Нажмите "Execute"
   - Увидите только книги Толстого

   **Фильтр по названию:**
   - В поле `title` введите: `Война`
   - Нажмите "Execute"

   **Фильтр по категории:**
   - В поле `category_id` введите: `1`
   - Нажмите "Execute"
   - Увидите только книги из категории 1

   **Комбинированный фильтр:**
   - `author`: `Толстой`
   - `category_id`: `1`
   - Нажмите "Execute"

### 4.3. READ - Получение книги по ID

1. Найдите **`GET /books/{book_id}`**
2. Нажмите "Try it out"
3. Введите `book_id` (например, `1`)
4. Нажмите "Execute"

### 4.4. UPDATE - Обновление книги

1. Найдите **`PUT /books/{book_id}`**
2. Нажмите "Try it out"
3. Введите `book_id`: `1`
4. В **Request body**:
   ```json
   {
     "title": "Война и мир",
     "author": "Лев Николаевич Толстой",
     "description": "Обновленное описание",
     "category_id": 1
   }
   ```
5. Нажмите "Execute"

### 4.5. DELETE - Удаление книги

1. Найдите **`DELETE /books/{book_id}`**
2. Нажмите "Try it out"
3. Введите `book_id` (например, `3`)
4. Нажмите "Execute"
5. Ответ: `204 No Content`

## Шаг 5: Тестирование Health Check

1. Найдите **`GET /health`** в разделе "default"
2. Нажмите "Try it out"
3. Нажмите "Execute"
4. Должен вернуться ответ:
   ```json
   {
     "status": "ok",
     "message": "API работает корректно"
   }
   ```

## Шаг 6: Проверка ошибок

Попробуйте создать ошибки, чтобы увидеть обработку:

1. **Создать категорию с пустым именем:**
   - `POST /categories` с `{"name": ""}`
   - Должна вернуться ошибка валидации

2. **Получить несуществующую категорию:**
   - `GET /categories/999`
   - Должна вернуться ошибка `404 Not Found`

3. **Создать книгу с несуществующей категорией:**
   - `POST /books` с `"category_id": 999`
   - Должна вернуться ошибка `404 Not Found`

4. **Удалить категорию с книгами:**
   - Попробуйте удалить категорию, в которой есть книги
   - Должна вернуться ошибка `400 Bad Request`

## Советы по использованию Swagger UI

- **Кнопка "Try it out"** - включает режим тестирования
- **Кнопка "Execute"** - отправляет запрос
- **Response body** - показывает ответ сервера
- **Response code** - код статуса HTTP (200, 201, 404 и т.д.)
- Можно сворачивать/разворачивать секции для удобства
- Все запросы логируются в консоли сервера
